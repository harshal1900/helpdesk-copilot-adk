# Password Reset SOP

## Self-service reset
Users can reset their password from the sign-in page by choosing "Forgot password". A reset link is emailed to the registered address and stays valid for 60 minutes.

## Locked accounts
After 5 failed sign-in attempts an account is locked for 15 minutes. Users can wait for the lock to expire or use the reset link to unlock the account sooner.

## When to escalate
If the user no longer has access to their registered email, escalate to the Identity team. Agents must not change the registered email without identity verification.

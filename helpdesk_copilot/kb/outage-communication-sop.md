# Outage Communication SOP

## Checking service status
Before replying to a ticket that says the service is down, check the public status page for active incidents.

## Replying during an incident
If an incident is active, tell the customer that the incident is acknowledged and link to the status page. Do not share root-cause details or restoration times until the incident is resolved.

## No active incident
If no incident is active, ask the customer for the affected region, the time the problem started and any error message. Set the priority to P2.
